## 5-1. 디자인 규칙 (모든 화면 공통)

- 색 = **차콜 바탕 + 볼트(형광 노랑 `#d7f548`) 강조 하나**
  - 지도 색(주황 오르막 · 빨강 가파름 · 파랑 내리막 · 초록 지나온 길)과 겹치지 않게
- **⭐ 보스 원칙 (11/17)**: 기능을 더해도 **담백하게**
  - 카테고리·배치를 늘리지 않는다. 기본값은 '전체'
  - 새 칸을 만들기 전에 기존 칸 안에서 해결되는지 먼저 본다
- **화면 색 두 벌**: 내 기록 → ⚙️ 설정 맨 위 `🌙 어두운 | ☀️ 밝은` · 기본 어두운 · `bgsj_skin` · 밝은 화면 = `<html data-skin="light">`
- **색은 변수로만** — `#fff` · `rgba(255,255,255,…)` · `color:var(--ch)`를 직접 적으면 밝은 화면에서 안 보임

| 쓰임 | 적는 법 | 어두운 | 밝은 |
|---|---|---|---|
| 바탕 · 칸 · 창 안 칸 | `--ch` `--ch2` `--ch3` | `#1b1c1f` `#26282c` `#34373c` | `#eef0ea` `#fff` `#e2e5dd` |
| 글자 · 옅은 · 흐린 | `--tx` `--tx2` `--mut` | `#fff` `#c9cbd0` `#9a9ca1` | `#1b1c1f` `#44474c` `#6a6e74` |
| 흰 반투명 | `rgba(var(--ink),α)` | 255,255,255 | 27,28,31 |
| 볼트 바탕 (버튼·고른 칩) | `--vt` + 글자 `--onv` | `#d7f548` + `#1b1c1f` | 같음 |
| 볼트 글자·테두리·얇은 선 | `--vtx` | `#d7f548` | `#5d7a00` (올리브) |
| 알림 카드 · 주의 · 그림자 | `rgba(var(--pop),.97)` `--warn` `--sha` | 38,40,44 · `#ff9d6e` · .5 | 255,255,255 · `#b5482f` · .16 |

- 운동 중 지도 위 칸의 밝은 색 = 스타일 맨 끝 `html[data-skin=light] …` 묶음 · 캔버스는 `isLight()`로 갈라 씀 (`drawFree` · `drawRealMap`)
- **화면을 고치면 두 모드 모두 캡처로 확인**
- 고르기 = 얇은 `.seg` · 보조 버튼 = 조용한 한 줄 `.toggle` · 창 안 칸 `--ch3`
- 운동 중 +/−·숫자는 크게 유지 (러닝머신 위 조작용)
- **누르는 칸 44px 이상**
  - 얇은 알약은 보이지 않는 덧칸(`::after`)으로 범위만 44px
  - 지역 칸·고르기·속도 버튼은 실제 44px · 일시정지·종료 48px
- 알림 카드·정보창·명소 카드도 차콜 (크림색 폐기) · 정복·도장 표시는 금색 대신 볼트
- 도착 알림 = 위쪽 칸 바로 아래 자동 배치 · 운동 중 안내 알림(토스트) = 아래쪽 조작판 위
- 가상 폰 시험은 폭 360 · 새 칸을 `#liveBox`에 넣을 때는 한 줄 전체(`flex-basis:100%`)인지 확인
- 폰 '뒤로' = 한 단계만 닫기
  - 팝업 → (운동 중이면 "끝낼까요?") → 내 기록·끝 화면 → 코스 화면 → 첫 화면 → 나가기
  - 웹 `backStep()` · 앱 `window.bgrBack()`
- **행사·광고 자리 3곳은 다른 것으로 채우지 말 것**
  - 첫 화면 카드 아래 / 고른 코스 한 줄 아래 / 완주·끝 화면
  - 내용 없으면 자리째 숨김 · 운동 중 화면엔 넣지 않음 · 자료 틀 `PROMO`

## 5-2. 코드를 고치는 모든 창의 규칙

1. 작업 전 main 최신 위에서 (올리기 직전에 다시 받기)
2. 올리기 전 `index.html` 맨 위 `const BUILD` 숫자를 앞 판보다 크게 (문서만 바꿀 때는 그대로)
3. 끝나면 main에 커밋·푸시 · zip 끌어다 놓기 금지
4. 예약 작업 창은 저장소 쓰기 권한 없음 → 앱 반영은 대화창에서
5. 공공데이터포털 인증키는 저장소·앱 코드에 넣지 않음 (브이월드 키·Supabase 공개 키는 공개용이라 예외)
6. 공식 노선 파일을 고치면 **파일 이름을 바꿀 것** (예: `loop2.json` → `loop3.json`) — 폰이 알아채고 다시 받음
7. `app/`나 `.github/workflows/android.yml`을 고치면 새 APK·AAB 자동 빌드 — 꼭 필요할 때만
8. 줄 끝 주석이 뒤 코드를 먹는 실수 주의 (11/18 3D 배터리 사고 · 11/21 앱이 안 뜨는 판) → 올리기 전 문법 검사 + 화면 확인
9. 코드 수정은 한 번에 한 작업창만 (`index.html` 한 파일이라 동시에 고치면 서로 덮어씀)
