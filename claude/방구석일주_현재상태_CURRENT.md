## 5. 앱 구조 (11/24 기준)

- **첫 화면**: 🏠 방구석(실내) / 🌳 바깥(GPS)
- **시작 화면**: 일반/테마 → 운동(걷기·조깅 / 자전거 / 등산·계단) → 찾기(내 주변 / 주제별 / 지역별) → 코스
- **거리 칩**: 걷기 3·5·10km · 자전거 10·20·40km · 산 오를 높이 300·600·1000m
- **목표 칩**: 남은 거리에 맞춤 (끝까지 N km · 한 바퀴)
- **운동 화면**
  - 보기 버튼 하나로 바꿈 (3D → 위성 → 지도) · 🎬 영상 버튼은 따로
  - 오른쪽 아래 운동 시간 크게 · 왼쪽 아래 최종 목표 크게 + 다음 거점 작게
  - 코스 영상을 멈추면 운동도 멈춤 · 쇼츠·음악은 멈춰도 운동 계속
  - 확인된 영상(`video.ok`)만 보임
- **산**: 실제 등산로가 있는 산은 3D·위성·지도 모두 · 바깥에서 테마 산 = 실시간 GPS 등산, 정상 60m 안 = 도장
- **현장 도장**: 바깥 GPS로 거점 80m 안에 실제로 가야 📍
- **🧪 실험실 (보스 폰만)**: 내 기록 제목 5번 톡 → 해외 코스(유럽 12곳 포함) · 지도 없는 길 · 등산로 없는 산
- **끝 화면**: '✓ 완료' 버튼 하나 · 1분 미만 또는 100m 미만은 저장 안 함
- **최고 속도**: 걷기·조깅 20km/h · 자전거 45km/h · 계단 레벨 최대 15
- **응원**: 문 열고 나오는 캐릭터(보스 캐리커처 '방구석 빌런') · 코스 지역 사투리 6종 · '화이링'은 보스가 고른 표기, 고치지 말 것
- **기록 백업**: 옮기기 코드(BGSJ1) + Keep 플러그인 → 안드로이드 자동 백업 → 재설치 후 비어 있으면 자동 복구
- **색**: 변수로만 (`--ch` `--tx` `--mut` `rgba(var(--ink),α)` 등). `#fff` 직접 쓰면 밝은 모드에서 안 보임
- **행사·광고 자리 3곳 (지금은 비워 둠)**: 첫 화면 카드 아래 · 고른 코스 줄 아래 · 끝 화면. 운동 중 화면엔 넣지 않음
